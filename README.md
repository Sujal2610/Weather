# # 🌦️ LoRa-based Weather Monitoring System

A wireless weather monitoring system built using ESP LoRa development boards to collect and transmit real-time environmental data efficiently over long distances. This IoT project is ideal for remote area applications such as agriculture, disaster management, and rural weather tracking.

---

##  Features

- 📡 Long-range communication using LoRa (10+ km range).
- 🌡️ Real-time sensing of:
  - Temperature & Humidity (DHT11)
  - Atmospheric Pressure (BMP180)
  - Light Intensity (LDR)
  - Rainfall Detection (Rain Sensor)
- 📟 Local LCD display of sensor readings using I2C-based LCD (LiquidCrystal_PCF8574 library).
- ⚙️ Efficient data transmission between sensor node and gateway node.

---

##  Components Used

- ESP LoRa Development Boards (Sender & Receiver)
- DHT11 – Temperature & Humidity Sensor
- BMP180 – Pressure Sensor
- LDR – Light Intensity Sensor
- HW-028 Rain Sensor
- LCD Display (I2C interface)
- Breadboard, jumper wires, battery pack
